                     HOTEL CITY PARK - CRM RELEASE                      
========================================================================

HOW TO RUN:
1. Double-click "HotelCityPark.exe"
2. The CRM server will launch and automatically open your web browser to:
   http://localhost:3000/hospitality

KEYBOARD SHORTCUTS IN THE LAUNCHER WINDOW:
- Press [O] to re-open the browser page anytime
- Press [R] to restart the server
- Press [Q] to cleanly stop and quit

HOW TO STOP:
- Press [Q] inside the launcher window or close the launcher window.
- Alternatively, double-click "Stop_HotelCityPark.bat" anytime.

SYSTEM REQUIREMENTS:
- Windows 10 or Windows 11 (64-bit)
- No Node.js installation needed (bundled portable runtime included).
